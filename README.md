# Kyryl Bogach

**Lead Software Engineer | AI Product Engineer**

Technical Lead and full-stack engineer with 9+ years in legal-tech, health-tech, and AI products. I specialize in event-driven architecture, secure multi-tenant platforms, and pragmatic AI systems.

[Website](https://kyryl.bogach.es) · [CV](https://link.bogach.es/CV) · [LinkedIn](https://linkedin.com/in/kyryl-bogach) · [Email](mailto:kyryl.bogach@gmail.com)

## What I work on

- **Technical leadership:** Lead senior engineers. Set conventions through code review and reusable agent skills.
- **Platform architecture:** Build domain event buses, event-sourced subsystems, and relationship-based authorization.
- **AI products:** Ship LLM features that pair deterministic data with bounded generation and audit records.
- **Reliability:** Improve performance, scalability, and infrastructure cost.
- **Developer experience:** Build CI/CD pipelines and automate delivery.

My main tools include TypeScript, Node.js, Next.js, PHP, and PostgreSQL.
